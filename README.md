# B站大航海详情公开安装包

本仓库只保存由私有源码仓库自动生成并验证的公开安装产物，不接受手工编辑构建文件。

- 油猴安装：打开 `userscript/bilibili-guard.user.js`。
- 油猴更新元数据：`userscript/bilibili-guard.meta.js`。
- Chrome/Edge ZIP：下载 `extension/bilibili-guard-extension.zip`，解压后以开发者模式加载。
- 当前版本和 SHA-256：查看 `latest.json`。
- 历史产物：查看 `releases/<version>/`。

油猴更新由 Tampermonkey/Violentmonkey 和用户设置控制。ZIP 或“加载已解压”安装的扩展无法静默替换自身，只会提示新版本；扩展商店安装版由浏览器负责升级。

公开 IP 属地显示使用匿名只读接口 `https://api.gscn.live/bw/api/public/bilibili/ip-location`，用户不需要令牌、Cookie、本机伴随服务或额外配置。安装包不会内置 B 站访问凭据；云端服务不可用时只显示固定提示，不影响大航海查询。

30 日流水汇总来自第三方公开统计接口 `https://vtb.cat/api/liver/space`，仅供参考，不是 B 站官方结算数据。初次读取只发送当前主播 UID、不携带 B站 Cookie 或访问码，并只保留 `Amount + Charge` 的安全数值总额；没有数据或接口不可用时显示固定提示，不影响大航海查询。只有接口明确返回 Cloudflare 挑战时，面板才显示人工验证卡片：用户在新标签打开当前主播的展示页 `https://vtb.cat/liver/<uid>` 完成验证后点击“验证完成，重新查询”，会对固定 API 路径进行一次重查；客户端不读取、保存或上传验证 Cookie。

油猴版可选的“查询签约状态”使用同一主机下的固定单 UID 只读接口。首次使用须通过油猴菜单设置可撤销访问码；访问码只保存在脚本本地，不包含在公开安装包中。结果会显示繁星状态；繁星时按期显示星级任务的起止日期和每月金额，明细不可用时显示固定安全状态，只有“可入会且非繁星”时显示是否为新主播。查询必须手动点击，不开放昵称、房间号、翻页或名单枚举；“不可入会”与空结果都不能解释为已签/未签当前公会。扩展版不显示该入口。

扩展和用户脚本不读取 B站 Cookie、浏览历史或浏览器档案，不持久保存成员名单，也不显示或收集精确 IP 地址。人工验证后的单次重查只由浏览器向同一第三方主机托管验证 Cookie，客户端不读取、保存或上传该 Cookie。签约查询的 B站 Cookie 只由云端加密保管，浏览器只持有专用访问码。问题请在源码仓库报告，不要提交账号数据、成员名单或凭据。

面板头部的主播名和 UID 可直接点击复制，复制后只显示短暂本地确认；不会额外读取或上传任何页面数据。最小化会收成 44px 圆形入口，仍可拖动并记住位置；恢复面板会自动刷新当前创作者详情。
